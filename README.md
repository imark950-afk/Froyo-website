# froyoonthego.com

Website for FROYO on the go, served by GitHub Pages at https://froyoonthego.com.
The booking app lives separately at https://app.froyoonthego.com.

## Status: live

Pages: `index.html` (home), `services.html`, `how-it-works.html`, `loyalty.html`.
`events.html` and `social.html` only forward old links to their new places.
`robots.txt` and `sitemap.xml` let search engines find the site.
